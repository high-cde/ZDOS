# ZDOS Hub — osservazione web

Source: https://zdos-hub.it/ (accessed 2026-08-29)

The public surface is titled `ZDOS SOCIAL // Public Signal Network`. It exposes Feed, Channels, DOOM Room, Links and Safety center. It has a text-only public feed with a 4,000-character post field and review of risky content; channels are marked realtime ready; registration uses public handle, password of at least 12 characters and optional email; login is available. The public directory allows links for Discord, WhatsApp, GitHub or Website, with review and no token/access requested. The safety center covers reports and moderation decisions.

Implication for ZRetro: this is currently a public social/signal surface, not a project build registry or artifact upload API. Integrate ZRetro through a local signed manifest and an explicit, authenticated Hub adapter; do not treat public posts as code execution, deployment, artifact storage or capability grants. No ROM, BIOS, malware or harmful operational instructions should be uploaded.
